# 工作区分组（@local/dsh-workspace-groups）

在左侧工作区区域加入可自定义的分组：创建、重命名、删除分组，并把**工作区**与**自由会话**（不属于任何工作区的会话）在分组内、分组外拖动摆放。

## 使用

侧栏工作区区域顶部：

- **＋ 新建分组**：列表最上方的入口，输入名称后回车即创建；`Esc` 取消。
- **添加工作区**（标题栏 `+`）：选择文件夹并立即在其中开始会话。
- **搜索**（放大镜）：按工作区名称、路径或会话标题本地过滤。
- **显示已归档**（归档图标）：显示已归档会话。

分组标题行悬停出现两个按钮：

- **铅笔**：就地重命名分组（也可双击分组名）。
- **垃圾桶**：删除分组，先显示确认条；组内工作区与自由会话回到「未分组」。

工作区标题行悬停出现三个按钮：新建会话（对话图标）、重命名工作区、删除工作区（同样带确认条）。

## 置顶快捷入口与插件设置

侧栏顶部新增「置顶快捷入口」区：把所有置顶会话额外集中显示为快捷入口。它只是同一批会话的另一个入口——点击打开的就是原本那个会话，**不改变原有的置顶逻辑**：置顶会话仍然留在各自工作区里、仍按官方规则排在最前，置顶/取消置顶也照旧。分组或工作区折叠时，快捷入口依然可见。

- 每个快捷入口行显示所属工作区名；点击打开会话，右键 / `⋯` 菜单照常可用。
- 关闭方法：工作区标题栏的齿轮按钮 →「工作区分组设置」→ 关闭「置顶区」开关。设置写入 Host（`$DSH_HOME/dsh-workspace-groups-settings.json`），跨重启有效；默认开启。
- 快捷入口为空时不占位置，也不会显示空标题。

## 任务运行区 / 任务完成区

工作区列表最上方会按需出现两段临时任务板：

- **运行中**：Agent 正在执行的会话。等待审批、计划审核或回答时圆点变黄。
- **已完成**：会话跑完、但用户还没点开查看的。点开任意一行即打开该会话，这一行随即从完成区消失。

两段的标题都可以点击收起，收起状态和分组布局一起保存在 `dsh.workspace.groups.v1`。搜索框同样作用于这两段。子代理会话、空会话和已归档会话不会出现在任务板里；任务板不改变任何会话或分组数据，只做临时展示。

运行区里的任务可以**右键 →「标记为已完成」**：它会立刻被临时放进完成区（即使这一轮其实还在跑，也以手动标记为准，不再出现在运行区）。点开这条完成项查看后它会从完成区移除；如果那一轮还在跑，也不会再弹回运行区，直到这一轮结束后再来新任务。

除了运行区任务行，**右键任意会话行**也会打开会话菜单，其中同样有「标记为已完成」（行尾 `⋯` 菜单里也有）。点它会把该任务放进完成区；查看过、已经从完成区消失的任务，随时可以右键对应会话行再次标记，重新放回完成区继续查看。手动完成的记录同样跨重启保留，直到点开查看。

### 跨重启保留

任务区是持久的：退出程序再打开，**已完成但没点开**的仍然在；退出时还在运行、重开后已经停下的任务会留在运行区并标注「已中断」，点开查看后同样移除。

持久化由插件的 Host 半边负责：记录写在 `$DSH_HOME/dsh-workspace-groups-tasks.json`，并通过同源接口 `GET/POST /__dsh-workspace-groups/tasks` 与页面同步。DSH 的 Web 界面每次启动可能使用不同的本地端口，页面 `localStorage` 会随端口变成一份新的空存储，所以它只作为同源缓存（`dsh.workspace.groups.tasks.v1`），不能作为唯一持久层。

## 拖动

- 拖动**工作区**到分组标题或分组空白处：移入该分组末尾。
- 拖到某个工作区行的上/下半部：插入到该位置（组内排序）。
- 拖到**未分组**区域：移出分组。
- **自由会话**同理（按会话行拖动）。
- 拖动**分组标题**到另一个分组标题：调整分组顺序。

拖动时会出现插入线或目标高亮；松手即保存。

## 持久化

分组布局保存在页面本地存储 `dsh.workspace.groups.v1`（与官方侧栏自己的视图状态同一层），刷新页面后保留。分组只是视图组织，不会改动文件夹、会话记录或工作区注册本身。

## 与官方侧栏的关系

`sidebar.workspaces` 是单占位槽，同一时刻只能渲染一个实现；本插件在优先级 `-1` 上声明该槽位以取代官方浏览器（官方在 `0`）。因此启用插件时，官方侧栏的**视图选项**（按工作区/工作区树/单列表、手动/按更新排序）与**远端全文搜索**不在此实现中；会话的置顶、归档、分叉、复制 ID、重命名等仍可通过会话行的 `⋯` 菜单使用。停用本插件即恢复官方侧栏。

组件渲染失败时插槽会自动回退到官方浏览器；插件内部也有一层错误边界。

## 目录

- `client.js`：全部侧栏 UI 与交互（`window.__ModuleLoader__.load`）。
- `index.js`：Host 半边，提供任务区与插件设置的持久化接口（`/__dsh-workspace-groups/tasks`、`/__dsh-workspace-groups/settings`），文件写在 `$DSH_HOME`。
- `cordis.patch.yml`：插入插件行。
- `locale/*.json`、`icon.svg`：插件管理中的标题、说明与图标。
- `test/smoke.cjs`、`test/host.test.cjs`：无浏览器环境下的渲染/交互与 Host 持久化冒烟测试（`node test/smoke.cjs`、`node test/host.test.cjs`）。
